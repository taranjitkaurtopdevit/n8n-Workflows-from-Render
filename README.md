**How to  create API in n8n?**

  1. Open n8n, go to settings
  2. Go to n8n API
  3. Create new Apikey set scopes or just go by default
  4. Set expiry date.
  5. Save it somewhere safe as it will not be shown again

**How to Create PAT on github**
  1. Login into your Github account
  2. click on the profile icon on top right
  3. Go to settings -> Developer Settings
  4. Click on Generate Token -> Classic
  5. Token will be generated.
  6. Save it somewhere safe as it will not be shown again.
